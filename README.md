\# ReachInbox Email Scheduler



A full-stack email scheduling application built as part of the ReachInbox assignment.



\## Features



\- Google authentication

\- Email campaign creation

\- CSV/TXT recipient upload

\- Scheduled email delivery

\- Configurable email delay

\- Hourly sending limits

\- Background email queue and worker

\- Sent email tracking

\- Delivery status and success-rate dashboard

\- Scheduled and sent email views

\- Responsive dark-themed interface



\## Tech Stack



\### Frontend

\- React

\- TypeScript

\- Vite

\- CSS



\### Backend

\- Node.js

\- TypeScript

\- Express

\- Prisma

\- PostgreSQL

\- Email queue and background worker



\### Infrastructure

\- Docker

\- Docker Compose
